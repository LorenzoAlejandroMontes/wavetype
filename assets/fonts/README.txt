Fonts used by the Wavetype live card (card_styles.py). All under the SIL Open Font License 1.1
(full text in OFL.txt).

Files (woff2, Google Fonts "latin" subset: U+0000-00FF, quotes, dashes, euro sign, etc.; words with
letters outside that subset are drawn with Segoe UI, see card_styles.covers):

  BricolageGrotesque-var-latin.woff2   Bricolage Grotesque (opsz, wght axes)   Stamp style
  JetBrainsMono-var-latin.woff2        JetBrains Mono (wght)                   Stamp style (timer, keys)
  Doto-var-latin.woff2                 Doto (wght)                             Glyph style (strikethrough, timer)
  SpaceGrotesk-var-latin.woff2         Space Grotesk (wght)                    Glyph style (body)
  SpaceMono-Regular-latin.woff2        Space Mono Regular                      Glyph style (footer)
  SpaceMono-Bold-latin.woff2           Space Mono Bold                         Glyph style (labels)
  Geist-var-latin.woff2                Geist (wght)                            Signal style (body)
  GeistMono-var-latin.woff2            Geist Mono (wght)                       Signal style (labels)

Provenance: the same files served by fonts.googleapis.com, copied unmodified.
